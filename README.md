# antaḥkaraṇa

Diagrama interativo das camadas do *instrumento interno* na psicologia do Vedānta e do Sāṃkhya, feito com React Flow.

## As camadas

| | | |
|---|---|---|
| **manas** — मनस् | *saṅkalpa · vikalpa* | oscila: propõe e retira, nunca fecha |
| **buddhi** — बुद्धि | *niścayātmikā vṛtti* | determina, conclui — o órgão onde *viveka* acontece |
| **ahaṃkāra** — अहंकार | *aham + kāra* | apropria: carimba a conclusão como "minha" |
| **citta** — चित्त | *smaraṇa · saṃskāra* | guarda: memória e impressões latentes |

Fora do conjunto, **ātman** — que não é camada. Não age, não decide, não lembra: só ilumina. O que se toma por "eu" é o *cidābhāsa*, o reflexo dessa luz em buddhi.

Nota sobre `buddhi`: não é *viveka*. Viveka é a faculdade discriminativa em exercício — separar *nitya* de *anitya*. Buddhi é o instrumento sutil onde essa discriminação se dá quando está afiado.

Patañjali inverte o peso do vocabulário: em vez de uma camada entre outras, *citta* vira o nome do aparato inteiro — daí *cittavṛttinirodha*.
